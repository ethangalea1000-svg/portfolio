Connexion

À quoi sert Supabase ?
Supabase est le service qui peut stocker ton compte et tes données en ligne. GitHub Pages affiche CyberLab ; Supabase peut gérer la connexion et, plus tard, la sauvegarde de ta collection dans le cloud.

Comment se connecter ?

  1. Créer un projet Supabase : va sur supabase.com, crée un compte puis crée un nouveau projet.
  2. Récupérer l'URL du projet : dans Supabase, ouvre les informations API du projet et copie la Project URL.
  3. Récupérer la clé publique : dans les mêmes informations API, copie la Publishable key (ou la clé publique héritée anon si ton projet l'utilise encore).
  4. Coller les deux informations ci-dessous : URL Supabase + clé publique, puis clique sur Enregistrer.
  5. Créer ton compte CyberLab : indique ton email et un mot de passe, puis clique sur Créer le compte. Selon la configuration de Supabase, un email de confirmation peut être demandé.
Important : ne colle jamais ici une clé secrète service_role ou sb_secret_…. La page doit utiliser uniquement une clé publique/publishable.

Et ma collection ?

Sans connexion, les cartes de CyberCalc sont enregistrées sur cet appareil dans le navigateur.

La connexion Supabase sert à préparer une sauvegarde liée à ton compte. La synchronisation complète des cartes dans une base Supabase n'est pas encore activée dans cette version.
